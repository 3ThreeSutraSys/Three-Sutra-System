# 🌳 三弦宇宙树 (Three-Sutra Cosmic Tree)

> 万物皆弦，弦弦相通，构建三弦宇宙的知识森林

基于"三弦系统论"的知识管理体系，以四大维度构建的开放协作生态。

## 🌱 四大维度

### 1. 理论树 (theory) - 思想的种子库
- 存放核心思想、理论框架、文献笔记、哲学基础
- 从种子到枝干，构建完整知识体系

### 2. 育种树 (lab) - 实验的实验室
- 存放草稿、代码原型、实验数据、测试文件
- 大胆试错，孵化创新想法

### 3. 森林树 (forest) - 应用的生态系统
- 存放应用实例、视觉设计、项目落地、资源整合
- 从实验室到现实，让理论开花结果

### 4. 共鸣场 (resonance) - 社区的共振空间
- 存放社区讨论、协作计划、用户反馈、参与指南
- 连接万物，激发集体智慧

## 🎯 核心原则
- **开放** (Openness)：所有知识开放共享
- **生长** (Growth)：持续迭代，自然进化
- **共鸣** (Resonance)：社区协作，相互启发
- **平衡** (Balance)：理论实践，虚实相生
